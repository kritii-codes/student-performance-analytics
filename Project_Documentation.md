
# Student Performance Analytics System

## 1. Project Title
Student Performance Analytics System

Name: Kriti Kumari

## 2. Objective
The objective is to develop a Python program that analyses student
marks and attendance and generates useful performance statistics.

## 3. Technologies Used
- Python: program logic, functions, loops and conditions
- NumPy: numerical calculations
- Pandas: loading and analysing tabular data
- CSV: storing the dataset
- VS Code: development environment
- GitHub: project hosting and version control

## 4. Dataset Description
The dataset contains 20 fictional student records.
It includes student ID, name, department, marks in Math, Python, PHYSICS,JAVA
and DSA, and attendance percentage.

## 5. Implementation
1. Created a CSV file containing student records.
2. Loaded the file using Pandas read_csv().
3. Checked that the required columns and data were present.
4. Calculated total marks using Pandas.
5. Calculated student averages using NumPy.
6. Assigned grades using a reusable function.
7. Determined pass/fail status using a loop and conditions.
8. Calculated class and subject statistics.
9. Identified the top three students.
10. Displayed the analysis in the terminal.

## 6. Key Features
- Total and average marks
- Grade assignment
- Pass/fail analysis
- Class performance statistics
- Subject-wise average analysis
- Top three performers
- Attendance analysis
