
# Student Performance Analytics System

## Overview
A Python-based data analysis project that processes student marks
and attendance to generate useful performance statistics.

## Objective
To analyse student performance using Python, NumPy and Pandas.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV for storing student records

## Features
- Reads student data from a CSV file
- Calculates total and average marks
- Assigns grades using defined thresholds
- Identifies pass/fail status
- Calculates class and subject averages
- Identifies the best-performing subject
- Displays the top three students
- Calculates average attendance

## Dataset
The dataset contains 20 fictional student records with student IDs,
names, departments, marks in three subjects, and attendance.

## How to Run
1. Install Python and the required packages.
2. Keep main.py and students.csv in the same folder.
3. Run the program using Python.

## Grading Rules
A: Average >= 90
B: Average >= 80 and < 90
C: Average >= 70 and < 80
D: Average >= 60 and < 70
E: Average >= 60 and < 50
F: Average < 50

A student passes only if they score at least 40 in every subject.

## Project Files
- main.py: Main analysis program
- students.csv: Student dataset
- README.md: Project overview
- Project_Documentation.md: Detailed project report

## Limitations
The dataset contains sample records and the grading thresholds
are illustrative. They are not official college grading rules.
